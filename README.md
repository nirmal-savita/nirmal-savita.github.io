## How it's built

A single static page, with no framework or build step.

- `index.html` holds the page, styles and a small script.
- `img/` holds the photos, badges and certificates.
- `.nojekyll` tells GitHub Pages to serve the files as they are.
- Hosted free on GitHub Pages from the `main` branch. The repository is named `nirmal-savita.github.io` to give the short address.
- It supports light and dark mode and works on phones.

## Updating the site

1. Edit `index.html`, or add images to `img/`.
2. Commit the changes to `main`.
3. GitHub Pages republishes the site within a couple of minutes.
